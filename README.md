### 🚀 Projetos em destaque

#### ✅ [Lista de Tarefas — React + Firebase](https://github.com/LuFMartins/aplicacao_web_de_lista_de_tarefas)

Aplicação de gerenciamento de tarefas com **cadastro e login de usuários, rotas protegidas e atualização de dados em tempo real**. Um projeto para praticar a integração entre a interface React e os serviços do Firebase.

`React` · `TypeScript` · `Firebase Authentication` · `Cloud Firestore` · `React Router`

`React` · `TypeScript` · `REST API` · `CSS3`

`React` · `TypeScript` · `Fetch API` · `Vite`
